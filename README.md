ESP-32 Sensor Dashboard

[Launch ESP32 Sensor Dashboard] (esp32-sensor-dashboard.anderson-wang368.workers.dev) *Uses mock values instead of real sensor values

The dashboard features sensor readings from the MPU6050 accelerometer/gyroscope and VL53L0X ToF module, including distance, acceleration, angular velocity and other derived values. These values are accompanied by a live 3D visualization of the MPU6050 module based on the fused pitch.
