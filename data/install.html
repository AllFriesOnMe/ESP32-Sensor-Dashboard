ESP32 DevKit / WROOM-32

This installer supports the classic ESP32 with 4 MB flash and an MPU6050 plus VL53L0X. ESP32-C3, S2, S3 and other chip families need a different firmware build.

Wire with power disconnected. For different SDA/SCL wiring, click Sensor setup beside Connect ESP32 on the dashboard; the wiring and scan dialog also opens automatically after connecting. Keep the board still during startup calibration and place a target in front of the distance sensor.

Install once, then connect

  1. Plug the board into your computer with a USB data cable. Close Serial Monitor and any dashboard tabs connected to it.
  2. Click Install firmware, select the board's serial port, and follow the installer.
  3. Wait for installation to finish, then close the installer dialog to release the USB port.
  4. Return to the dashboard and click Connect ESP32 (USB). Select the same port and wait for live readings.

Installing replaces the board's current program. Choosing to erase also removes saved settings and files. Save anything you need first. This firmware uses USB; no Wi-Fi password is required.

Use desktop Chrome or Edge to install over USB. Open this page over HTTPS or localhost to install.

Board not connecting?

Check your USB cable and serial driver. Close other apps using the port. If the installer stays at Connecting, hold BOOT while it connects, then release it when writing begins. Keep the cable connected until installation finishes.
